# Auckland Discovery Site launch brief

**Status:** agreed product direction; implementation has not started.

## Launch objective

Attract and learn from Auckland traffic while giving visitors a useful early
property-planning experience. The launch is not a pool-builder marketplace,
quote engine, or marketing programme.

## Audience and promise

The site serves both Homeowners and Pool Builders. Both enter through the
same address-based **Check my Auckland property** experience. The public
promise is an early, preliminary view of a property's pool-planning context;
it is not approval, certification, engineering advice, or a builder quote.

## Homepage

The hero uses a short, silent, lightweight map-style animation:

1. Enter an Auckland address.
2. See the property map.
3. Reveal local planning signals.
4. End on the live **Check my property** action.

## Property Check journey

1. A visitor checks an address and can move and rotate an interactive pool
   concept on the map.
2. Before the form, show a free preview: map/layout, space or access signals,
   and any `Needs Checking` constraints.
3. Before the detailed personalised report, require a report request with:
   name, phone, email, locked checked-property address, additional information,
   Visitor Type (Homeowner, Pool Builder, Other), and Project Timing (ASAP,
   within 3/6/12 months, Other).
4. Selecting Other requires a short explanation. The required consent covers
   storing the request and delivering the report only; there is no marketing
   opt-in at launch.
5. Deliver the detailed report in-browser and by email.

## First public pages

1. **Check my Auckland property** — the interactive tool.
2. **Can my Auckland property suit a pool?** — plain-language space, access,
   slope, hazards, and limits.
3. **Auckland pool planning for builders** — early site checks, planning
   context, and explaining constraints to homeowners.

Do not publish an Auckland price guide yet. Current research supports only
future internal calibration, not public ranges or automated pricing. See
[Auckland base-pricing research](./auckland-pool-base-pricing-research.md).

## Measurement boundary

Use Google Search Console plus GA4, with no Google Ads linking, audience
building, retargeting, session recording, or marketing profiles. Track only
anonymous progression events: Property Check start, preview shown, report-form
opened, report requested, email delivered, and report opened. Never send names,
phone numbers, email addresses, exact addresses, coordinates, or report content
to analytics.

Treat the first 90 days after launch as a learning period. Review Search
Console and GA4 weekly, then prioritise improvements from non-branded search
queries, landing-page performance, Property Check starts, and report requests
rather than a traffic target without a baseline.

## Deferred work

- Pool Builder Match and Future Builder Network.
- Lead sharing and partner consent.
- Public price ranges, calculators, or quotes.
- Marketing emails and newsletter consent.

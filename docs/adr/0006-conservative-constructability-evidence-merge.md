# Preserve constructability concerns across evidence sources

PoolReady conservatively combines mapped/API evidence with user-declared Site answers for constructability reporting. A concern identified by either source remains `Needs checking`; a user selecting “None of these” cannot erase a mapped concern, and apparently clear mapped evidence cannot erase a condition declared by the user. When sources disagree, the consolidated Preliminary report retains and explains both rather than allowing either source to cancel the other, because neither source independently proves onsite conditions.

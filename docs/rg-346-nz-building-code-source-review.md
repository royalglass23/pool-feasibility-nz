# RG-346: New Zealand Building Code source review

Reviewed 22 September 2026. **Decision: the New Zealand Building Code cannot supply the numeric working-clearance or base-allowance values for RG-346.** A named pool builder is not a statutory requirement. PoolReady can instead use a verified current pool-installation standard or an approved manufacturer/model specification, with its scope recorded; builder confirmation is one evidence route rather than the only route.

## Direct answer: New Zealand pools are not all fibreglass

The New Zealand residential market includes at least premoulded fibreglass/FRP shells, custom steel-reinforced shotcrete pools, concrete-masonry pools, steel-panel pools with vinyl liners, and prefabricated above-ground or partly in-ground systems. These categories overlap: a vinyl liner is a watertight finish and may be fitted over concrete, fibreglass or a proprietary panel structure, while “above-ground” describes the installation position rather than one shell material.

Primary New Zealand evidence includes [Leisure Pools NZ's premoulded fibreglass installation process](https://leisurepools.co.nz/buying-a-pool/6-simple-steps-of-fibreglass-pool-installation/), [Concrete Techniques' custom reinforced-shotcrete pools](https://www.concretetechniques.co.nz/shotcrete-spa-pools-and-swimming-pools/), [Firth's concrete-masonry pool system](https://www.firth.co.nz/assets/Uploads/Resources/Documents/FIR0744-Masonry-Swimming-Pools.pdf), [Cascade's steel-wall/concrete-floor vinyl-liner system](https://www.cascade.co.nz/downloads/ConstructionQAProgramme_Generic_.pdf), and [Paramount's in-ground, semi-in-ground or above-ground steel-panel vinyl-membrane system](https://paramountpools.co.nz/wp-content/uploads/2021/11/Paramount-Brochure-Web-CoastalModular.pdf). These sources establish that the construction types are genuinely offered or installed in New Zealand; they do not establish market share.

### What the numbers mean

The Firth **300 mm** and Cascade **250 mm** figures are not competing answers to one generic question. They start from different reference faces and support different structures. Likewise, the Firth 100 + 25 + 125 mm build-up, Cascade 40 + 70 mm floor, and Compass 110 mm slab are construction-system layers, not universal “extra depth below selected pool depth”. PoolReady would need a per-system datum contract before turning any of them into cubic metres.

**Result for RG-346:** a single “NZ pool allowance” setting is not defensible. PoolReady therefore uses a transparent planning control: 300 mm per side by default, adjustable from 200–600 mm, with values below 300 mm marked `Needs checking`. This range is not described as acceptable construction practice. Verified presets per construction system or selected manufacturer/model remain future work.

## Regulatory boundary

- [Building Act 2004, sections 16–17](https://www.legislation.govt.nz/act/public/2004/72/en/latest/) makes the Building Code a set of functional requirements and performance criteria and requires building work to comply. It does not prescribe how much wider or deeper a residential-pool excavation must be.
- [Building Code clause B1 — Structure](https://www.legislation.govt.nz/regulation/public/1992/0150/latest/DLM162576.html?tagf=1) requires buildings, building elements and sitework to remain stable, account for earth pressure, water, removal of support, construction uncertainty and site variation, and avoid damage to other property. Those are performance outcomes, not a pool quantity formula.
- [MBIE's explanation of compliance pathways](https://www.building.govt.nz/building-code-compliance/how-the-building-code-works/different-ways-to-comply/acceptable-solutions-and-verification-methods) confirms that the Code is performance-based. Acceptable Solutions and Verification Methods are non-mandatory ways to demonstrate compliance; alternative solutions may also be used.
- The current [B1/AS1 second edition](https://www.building.govt.nz/assets/Uploads/building-code-compliance/b-stability/b1-structure/asvm/b1-structure-as1-second-edition.pdf), effective 28 July 2025, covers masonry, steel, timber and earth buildings plus stucco, drains and glazing. It contains no residential-pool excavation working-clearance or base-allowance rule. Its foundation dimensions apply only within the cited systems and scope and cannot be transferred into a generic pool-volume estimate.
- [Building Code clause F9](https://www.legislation.govt.nz/regulation/public/1992/0150/latest/DLM162576.html?tagf=1) and MBIE's [residential-pool guidance](https://www.building.govt.nz/building-code-compliance/f-safety-of-users/pool-safety/residential-pool-provisions-of-the-building-act-2004-guidance-for-territorial-authorities/building-work-involving-residential-pools) govern restricting children's access and pool barriers. They do not define the excavation footprint or base construction.

## Dedicated fibreglass-pool standard route

Standards New Zealand lists [NZS AS 1839:2025](https://www.standards.govt.nz/shop/NZS-AS-18392025) as the **current** standard, published 28 August 2025. It is a modified adoption of AS 1839:2021 for installing premoulded fibre-reinforced plastic pools. The public product page exposes the scope and contents—including bedding, backfill, excavation profile, in-ground and above-ground installation, drainage and reactive-clay provisions—but not the normative clause text or its numeric requirements. SPASA NZ states that the standard [is not currently referenced in legislation or the NZ Building Code](https://www.spasa.co.nz/news/spasa-drives-development-of-nz-standards-for-fibreglass-pools), although it can have contractual or project-specific effect when referenced in plans, specifications or a contract.

Standards New Zealand also published a 2025 [public consultation draft for DZ 1839](https://consultations.standards.govt.nz/draft-standards/1838-39-pc/user_uploads/dz-swimming-pools-1839-draft_pc.pdf). Its New Zealand variations require site investigation and competent-person input where an installation is within the influence of structures or on reactive, sloping, reclaimed, filled or otherwise adverse land.

This is the right standards route for an ordinary fibreglass-pool default, but the consultation document is expressly a **draft that must not be used as a standard** and the Standards NZ preview does not expose the normative numeric installation clauses. Before RG-346 adopts any values, obtain and inspect a licensed copy of NZS AS 1839:2025 and record its exact clauses, units, reference edges, scope and exclusions. Do not reuse values from the superseded AS/NZS 1839:1994 without checking the current edition.

### Lawful internet search for the final 2025 numeric clauses

A further public-web search on 22 September 2026 did **not** locate a lawful public copy of the final NZS AS 1839:2025 normative clauses or a first-party source quoting its exact excavation-profile, side-clearance, bedding-depth or installation-tolerance figures. Standards New Zealand's [access guidance](https://www.standards.govt.nz/get-standards/buy-or-subscribe-to-standards) confirms that the standard is supplied through paid PDF, hard-copy or subscription access, and its [copyright guidance](https://www.standards.govt.nz/get-standards) says published standards are protected from unauthorised copying. Search results that purport to offer full standards outside those authorised channels were not used.

The strongest public first-party evidence is narrower:

- The [Standards New Zealand product page](https://www.standards.govt.nz/shop/NZS-AS-18392025) identifies NZS AS 1839:2025 as the current modified adoption of AS 1839:2021, but exposes only its scope and contents rather than the normative dimensions.
- SPASA's [publication summary](https://www.spasa.co.nz/news/spasa-drives-development-of-nz-standards-for-fibreglass-pools) identifies the New Zealand changes as site investigation, hydrostatic-valve, bond-beam and reactive-clay provisions. It does not publish numeric excavation or bedding requirements.
- The public consultation document exposes the proposed New Zealand variations and says the underlying AS 1839:2021 text was the adoption base. It expressly says the draft must not be used as a standard. The final public SPASA change summary is consistent with those subject areas, but that does **not** prove that every unlisted numeric clause is unchanged in the final edition.
- [Narellan Pools NZ](https://online.flippingbook.com/view/971353017) says each self-install pool is supplied with model-specific dig specifications, shell engineering and installation guidelines, and that installation must follow those documents and applicable standards. Its public brochure still names the superseded 1994 standard, so it is useful evidence for the model-specific-document route, not for a current standard number or default dimension.
- [Leisure Pools NZ](https://leisurepools.co.nz/buying-a-pool/6-simple-steps-of-fibreglass-pool-installation/) likewise says its installer receives a 3-D model-derived dig sheet containing the hole dimensions and progressive depths. This is the strongest currently available lawful source for PoolReady's immediate rule: use the selected pool model's current dig sheet rather than infer a generic hole from nominal water dimensions.

Some Australian pool installers publicly attribute figures such as an approximately 100 mm free-draining bedding layer, a 1-in-300 final-level tolerance, and a 50 mm water-level relationship to AS 1839:2021. Those statements are secondary summaries of the Australian edition, not first-party text from NZS AS 1839:2025. They are useful leads for checking a licensed copy but are **not verified RG-346 inputs** and must not be presented as current New Zealand requirements.

**Internet-search conclusion:** the 2025 standard can be named as the governing fibreglass installation reference and its public New Zealand adverse-site variations can support `Needs checking` rules. It cannot yet supply PoolReady's numeric excavation volume. Until licensed clauses are available, the defensible numeric path is a current manufacturer/model dig sheet; if no dig sheet is selected, retain any existing 300 mm calculation only as the already disclosed Firth-masonry proxy, never as an NZS AS 1839 value.

### What the public Venice 10.5 documents establish

The NZ listing gives estimated dimensions of **10.50 m long x 4.40 m wide**, **1.14 m shallow**, **1.98 m deep**, and **53,000 L**. It warns that physical shells can vary from supplied drawings and that all dimensions are approximate.

The public Barrier Reef `POOL SHELL SPECIFICATION/DIG SHEET` gives:

- 10.50 m external length and 4.40 m external width;
- 10.30 m internal length and 4.20 m internal width;
- 9,460 mm screed length and 9,760 mm floor length;
- profile dimensions of 1,100 mm and 1,930 mm; and
- an approximate water volume of 57,850 L.

Those profile and volume figures do not match the current NZ listing. The sheet does not expose an issue date or an NZ revision identifier, so this review cannot establish that it is the current drawing supplied for a New Zealand Venice 10.5 installation.

The repeated **100 mm** labels on the drawing describe shell features, including the perimeter safety ledge and wall geometry. They are **not** an excavation clearance or base allowance. The sheet supplies no numeric working-clearance offset from the external shell, no bedding/base thickness or material specification, no finished-grade datum, no drainage layout, and no numeric backfill thickness. None of those values may be inferred from the drawing.

### RG-346 rule supported by this example

PoolReady may identify the Venice 10.5 as an example of why a selected model and revision are required, but it must not calculate a full excavation volume from the public documents above. A usable model setting still requires the current NZ-issued dig sheet or installation pack to provide, or explicitly approve:

1. shell and excavation reference edges;
2. hole dimensions or per-side overdig;
3. base/bedding thickness and material;
4. the vertical datum for every depth;
5. drainage and backfill requirements; and
6. the drawing revision and applicable site-condition exclusions.

Until those fields are available, Venice 10.5 remains `Needs checking`; the public shell geometry must not be combined with the unrelated 300 mm Firth masonry proxy and presented as a manufacturer-derived fibreglass quantity.

## Safety guidance is not the missing product dimension

[WorkSafe's excavation guidance](https://www.worksafe.govt.nz/topic-and-industry/excavation/excavation-safety-gpg/) says excavation method and controls depend on site-specific ground, groundwater, nearby structures, services, loads and access. Its `zone of influence plus 1 m` guidance keeps plant, vehicles, spoil and heavy loads away from an excavation edge unless specifically designed; it is not one metre of clearance around a pool shell. WorkSafe also notes that this guide has not been updated to reflect current work-health-and-safety legislation, so it is practical safety guidance rather than a current-law compliance determination.

An official 2025 MBIE [determination concerning an in-ground concrete pool](https://www.building.govt.nz/assets/Uploads/resolving-problems/determinations/2025/2025-045.pdf) illustrates the distinction: that pool's consent contained a project-specific section and a producer statement for its excavations, foundations and retaining walls. The dimensions in that consent described that pool; the determination does not create a universal allowance.

## Consequence for RG-346

We cannot replace construction evidence with a generic claim that a number comes from “the NZ Building Code”. The Code supports the warning and assessment boundary—stability, groundwater, neighbouring property and site-specific design—but not the numeric volume inputs.

RG-346 can use any of these evidence routes:

1. the verified current NZS 1839 installation provisions for ordinary premoulded fibreglass pools within that standard's scope;
2. an identified pool model's current manufacturer dig sheet and engineering specification;
3. a construction-system specification limited to that exact system, such as the existing Firth masonry example; or
4. a documented rule approved by a competent pool builder or engineer for a stated range of pool types and site conditions.

For every future verified route, record the source/version, reference edge, side clearance, base build-up, supported construction type and depth range, exclusions, and approval or design authority. RG-346 retains the existing 300 mm Firth-derived value only as the disclosed starting point for a user-adjustable side-only planning scenario. Neither the default nor another user selection becomes a generic fibreglass or all-pool construction value.

## Trust and exposure boundaries

- Browser to public Next.js routes: untrusted input and bearer capability boundary.
- Next.js to Neon/Upstash/Resend/LINZ: server credential and availability boundaries.
- Resend and ServiceM8: external processor/disclosure and retention boundaries.
- PDF renderer: untrusted saved text/URLs cross into HTML/Chromium; network requests are aborted but link schemes still require positive validation.
- Playwright artefacts and local logs: evidence surfaces that must stay free of tokens, credentials and PII.

## Minimisation and lifecycle judgment

The public API returns the report or two channel-state values rather than raw rows/provider payloads. Neon has a documented 12-month deletion path and privacy-request process. Production delivery remains gated because ServiceM8 irreversible deletion is unproven and current cross-border/processor-safeguard evidence is incomplete. No production data or provider account was accessed in this audit.

# Data classification - MT-260 traffic launch

| Data                                                               | Classification                | At rest                                            | In transit                                                 | Retention                                      | Logging and notes                                                                        |
| ------------------------------------------------------------------ | ----------------------------- | -------------------------------------------------- | ---------------------------------------------------------- | ---------------------------------------------- | ---------------------------------------------------------------------------------------- |
| Name, phone, email                                                 | Personal (PII)                | `homeowner_assessments`                            | Browser, Neon, Resend; ServiceM8 notification when enabled | 12 months                                      | Never URL, analytics, trace, screenshot, or log data.                                    |
| Checked address, parcel, coordinates, layout, warnings, report/map | Personal/property-sensitive   | Assessment columns and JSONB                       | Browser, Neon, homeowner PDF/email                         | 12 months                                      | ServiceM8 must not receive map, PDF, full report, coordinates, parcel ID, or report URL. |
| Visitor type, timing, Other details, message                       | Personal/confidential         | Assessment columns                                 | Browser, Neon; minimal ServiceM8 notification              | 12 months                                      | Free text may contain unexpected sensitive data; never log or send to analytics.         |
| Report-delivery consent/version/time                               | Personal compliance record    | Assessment columns                                 | Browser to app to Neon                                     | 12 months                                      | Delivery consent is not analytics or marketing consent.                                  |
| Analytics consent choice                                           | Personal browser preference   | Browser local storage only                         | Browser only until allowed GA4 script loads                | Visitor-controlled                             | No report or property fields are permitted in analytics events.                          |
| Admin username/password hash                                       | Confidential / secret-derived | Staff account table; salted scrypt hash            | Sign-in form over TLS                                      | Until manual reset/reprovision                 | Password and hash must never enter client bundles, logs, or evidence.                    |
| Staff session token                                                | Secret                        | Hashed server-side session record; HttpOnly cookie | Browser over TLS                                           | Maximum 8 hours; invalidated on sign-out/reset | Never committed in Playwright storage state or artifacts.                                |
| Failed-attempt and lockout state                                   | Internal security data        | Staff account row                                  | Server/database                                            | Operational account lifetime                   | Five failures cause a 15-minute lock; record no password.                                |
| Client IP / rate-limit key                                         | Personal/operational          | Hashed key in managed rate-limit store             | App to Upstash-compatible store                            | Store window                                   | Logs contain action/outcome/correlation only, not IP or payload.                         |
| Delivery message IDs and bounded error codes                       | Internal                      | Delivery state columns                             | Provider to app/database                                   | With assessment                                | No raw provider response or destination secret.                                          |
| Retention run ID/time/cutoff/count                                 | Internal audit data           | `report_request_retention_runs`                    | App/database                                               | Operational audit policy                       | Deliberately excludes deleted PII.                                                       |
| Database, signing, cron, Redis, provider credentials               | Secret                        | Environment/secret store only                      | Server-to-server TLS                                       | Platform rotation policy                       | No values were read into this evidence.                                                  |

## Code-verifiable NZ Privacy scope

The public notice, 12-month deletion path, support request channel, processor disclosure, purpose limitation, and analytics separation now exist in code. Release proof remains incomplete because no dedicated MT-260 database/delivery/store environment was available to exercise IPP5, IPP9, IPP11, or IPP12 across the real runtime boundary.
